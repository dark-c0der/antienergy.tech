METHOD / LIMITS / SOURCES

Truth before spectacle.

Antienergy separates published astronomical data from visual interpretation so you can tell what is measured, modelled, derived, or unavailable.

01

Data provenance

Solar-system metadata and orbital parameters are sourced from NASA/JPL Solar System Dynamics. The app keeps units, epoch, frame, source, and coverage alongside each value.

JPL Solar System Dynamics ↗
02

What you see

The default explorer uses one physical kilometre conversion for the Sun, planets, and published satellite radii. Jupiter is about 10.97 Earth diameters and about 1,321 Earth volumes; those relationships are preserved.

Use Focus selected to move the camera into a body-scale view. Exploration scale remains proportional between bodies while making distant worlds easier to inspect.

03

Ephemeris status

The runtime attempts JPL Horizons for supported state vectors. When live access is unavailable, a versioned orbital-element fallback keeps the site usable and labels the result as an approximation.

Horizons API documentation ↗
04

Catalogue boundaries

“Known” means published and catalogued. A missing moon or exoplanet measurement does not mean the object does not exist; it means this interface does not have a reliable value to show.
