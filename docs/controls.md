# Controls

- Drag to orbit, scroll/pinch to zoom, and right-drag (or two-finger drag) to pan.
- Select a body from the explorer or click a body in the scene.
- Use the timeline slider, step buttons, or Play to change the simulation clock.
- Choose a playback speed, toggle orbital paths/labels, and switch between Exploration and True Scale.
- Reset the camera or focus it on the selected body.

All timestamps in the interface are UTC. The current display is intentionally explicit about whether it is source-backed live data or an approximate fallback.
