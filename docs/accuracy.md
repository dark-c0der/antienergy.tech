# Accuracy and display modes

The explorer uses heliocentric, ecliptic-style coordinates for the bundled fallback model. Values are represented in astronomical units (AU) in the calculation layer and converted only at the renderer boundary. In true physical scale, one astronomical unit and every published body radius use the same kilometre conversion, so the Sun is not enlarged relative to planetary distances.

**True physical scale** is the default: one kilometre conversion is used for the Sun, planets, moons, and orbital distances. This means a whole-system view naturally makes planets tiny. **Exploration scale** is an explicit readability mode that exaggerates body radii and compresses distances. Neither display mode changes the underlying catalogue values.

The current initial release interpolates a Keplerian approximation from published mean orbital elements. Live JPL Horizons state-vector support is attempted, but the result is only marked live after a valid vector response is parsed. The app never describes the fallback as exact and exposes source/coverage text in the selected-body panel.

The asteroid belt is a procedural visual sample placed between Mars and Jupiter. It uses 1,200 deterministic 3D bodies distributed from approximately 2.15 to 3.25 AU with varied sizes, eccentricities, and orbital-plane inclinations. Each body uses one of several opaque, rounded-but-irregular low-poly rock meshes with restrained surface variation, independent elongation, and rotation; they are not rendered as spheres or spiky transparent polyhedra. Sample radii range from approximately 0.08 to 34 km and remain proportional in true-scale mode, so no sampled asteroid can visually become planet-sized. This is intentionally far fewer than the millions of known asteroids; it communicates the belt's structure without claiming to render the complete small-body population. The Sun receives a separate display-only corona, animated layered halo, and minimum readability disc in the 10 AU view; its published catalogue radius remains unchanged in the data layer.

Moon orbital planes are not all coplanar. The fallback includes explicit inclined and retrograde cases such as Himalia, Carme, Ananke, Pasiphae, Iapetus, Phoebe, and Triton, while catalogue moons without individual inclination fields receive deterministic fallback planes. These are orbital-plane visualizations, not claims that every missing element has been measured in this bundle.
